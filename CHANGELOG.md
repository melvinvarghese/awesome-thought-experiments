# Changelog

## 2026-10-31 — Expansion to 132 entries

- Added 57 articles, each with the ten required sections, a dataset record, a README entry and at least one academic reference: ethics (5), identity (4), consciousness (4), epistemology (10), logic (7), time and causality (5), physics (6), mathematics (3), economics (3), society and justice (3), artificial intelligence (5) and science and biology (2).
- Added four learning paths: Language, Meaning, and Self-Reference; Science, Evidence, and Explanation; Time, Fate, and Freedom; and Cooperation, Choice, and Collective Decisions.
- Added 20 sections to the connections guide for the new entries.
- Added [research/expansion.md](research/expansion.md), which records the status, title and topic-keyword counts for every new reference, and lists candidate entries that were left out because the pages checked did not support them.
- Fixed the validator and its tests so they read and write UTF-8 explicitly. They previously raised a decoding error on Windows.
- Updated the quality report and getting-started guide.

## 2026-10-30 — Initial collection

- Added original educational articles with scholarly references and explicit type labels.
- Added seven guided learning paths, a connections guide, and a categorized README.
- Added a JSON dataset and schema, standard-library validation, contribution guidance, and GitHub issue and pull request templates.
- Packaged the collection for manual GitHub upload. No repository was published during production.
