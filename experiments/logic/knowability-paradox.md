# Fitch’s Paradox of Knowability

**Category:** logic  
**Type:** paradox  
**Associated thinker(s):** Frederic Fitch  
**Original publication or approximate period:** Fitch, “A Logical Analysis of Some Value Concepts” (Journal of Symbolic Logic, 1963)  
**Difficulty:** Advanced  
**Themes:** knowability, verificationism, modal logic  
**Related experiments:** [The Unexpected Hanging / Surprise Test](unexpected-hanging.md); [The Liar Paradox](liar.md)

## 1. The Scenario

Suppose that every truth is knowable: if something is true, then it is possible that someone knows it. This looks like a modest thesis, held by some verificationists.

Now consider a truth p that nobody ever knows. Then “p is true and nobody ever knows p” is a truth. By our supposition it must be knowable. But knowing a conjunction means knowing each part. So someone would know that p and know that nobody knows p, which is impossible. So there are no unknown truths: every truth is known.

## 2. The Central Question

Does the plausible thesis that all truths are knowable commit us to the implausible thesis that all truths are known?

## 3. Why It Matters

The argument is short, uses weak logical principles, and has a striking conclusion. It is a test for views that link truth to knowability, including some forms of anti-realism, which hold that truth cannot outrun what could be known.

It also illustrates how logical reasoning about knowledge can bring out hidden commitments, and it is related to other paradoxes of self-reference and unknowability.

## 4. Major Interpretations

**Rejecting the knowability principle** says that some truths are unknowable, and this is the straightforward lesson. **Restricting the principle** to certain kinds of statements blocks the proof. **Revising the logic** by adopting a non-classical logic avoids the final step. **Reinterpreting knowability** as a different modality avoids the conclusion. Each has costs.

## 5. Common Misunderstandings

The proof does not show that we know everything, and it does not depend on any claim about how much we actually know. It shows that if one holds the knowability principle with classical logic, one must accept the conclusion. Credit for the underlying argument is discussed in the literature, and the paper’s title does not reflect its famous use.

## 6. Think for Yourself

1. Which step would you reject, and why?
2. Is there a truth that can be stated but never known?
3. Does the paradox threaten anti-realism, or only a naive version?
4. How does this compare with Moore’s paradox, “p but I don’t know that p”?

## 7. Variations and Extensions

Restricted principles, such as knowability only for “Cartesian” propositions, have been proposed. The paradox can also be formalized in a variety of modal systems.
