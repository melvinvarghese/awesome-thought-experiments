# The Stag Hunt

**Category:** economics  
**Type:** model  
**Associated thinker(s):** Jean-Jacques Rousseau  
**Original publication or approximate period:** Rousseau, Discourse on the Origin and Foundations of Inequality (1755); later formalized in game theory  
**Difficulty:** Intermediate  
**Themes:** coordination, trust, risk  
**Related experiments:** [The Prisoner’s Dilemma](prisoners-dilemma.md); [The Tragedy of the Commons](tragedy-of-the-commons.md); [The State of Nature](../society-and-justice/state-of-nature.md)

## 1. The Scenario

Two hunters can each choose to hunt a stag or a hare. A stag can only be caught if both hunters cooperate, and it feeds both well. A hare can be caught by one hunter alone, but it is a smaller meal. If one hunter goes after the stag and the other goes after a hare, the stag hunter gets nothing.

An illustrative payoff table is below. Each cell lists the payoffs to Player 1 and Player 2.

| | Player 2 hunts stag | Player 2 hunts hare |
| --- | --- | --- |
| **Player 1 hunts stag** | 4, 4 | 0, 3 |
| **Player 1 hunts hare** | 3, 0 | 3, 3 |

## 2. The Central Question

When cooperation is best for everyone but risky, what lets people trust each other enough to coordinate?

## 3. Why It Matters

Unlike the prisoner’s dilemma, the stag hunt has no dominant strategy. Both players hunting stag is an equilibrium, and so is both hunting hare. The problem is not temptation to cheat but uncertainty about what the other will do.

This models cases such as joining a protest, adopting a shared standard, or investing in a joint project. It suggests that institutions, communication and reputation can solve problems that incentives alone do not.

## 4. Major Interpretations

**Payoff-dominance** favours the stag equilibrium because both do better. **Risk-dominance** favours the hare equilibrium because it is safer under uncertainty. **Evolutionary models** study which equilibrium populations settle into. **Political readings** treat the game as showing how social order depends on mutual assurance, as in Rousseau’s own use of the example.

## 5. Common Misunderstandings

The numbers in the table are only one example; the game depends on the ordering of payoffs. The stag hunt is not a prisoner’s dilemma, and mixing them up hides that the main obstacle is trust and not defection. Rousseau did not state a formal game.

## 6. Think for Yourself

4. How would repeated play change the analysis?

## 7. Variations and Extensions

Versions with more players require a minimum number to cooperate. These “threshold” games model collective action problems, and they can behave differently from the two-person version.
