# Start Here: 10 Thought Experiments for Beginners

Begin with concrete cases, then ask how much the imagined setup has already assumed. You can read one entry at a time; no prior philosophy is required.

## Learning objectives

- Separate a scenario from the conclusion someone draws from it.
- Identify a premise that changes your answer.
- Compare a moral intuition, a logical contradiction, and a probability calculation.

## Recommended sequence

1. [Trolley Problem](../experiments/ethics/trolley.md) — Record your initial judgment before reading the replies.
2. [Ship of Theseus](../experiments/identity/ship-of-theseus.md) — Decide what you mean by “the same.”
3. [Experience Machine](../experiments/ethics/experience-machine.md) — List what you value beyond pleasant experiences.
4. [The Ring of Gyges](../experiments/society-and-justice/ring-of-gyges.md) — Ask whether a reason to be moral survives invisibility.
5. [Chinese Room](../experiments/consciousness/chinese-room.md) — Separate performing a task from understanding it.
6. [Mary’s Room: The Knowledge Argument](../experiments/consciousness/marys-room.md) — Compare knowing a description with having an experience.
7. [The Dream Argument](../experiments/epistemology/dream-argument.md) — Distinguish practical confidence from certainty.
8. [Sorites: When Does a Heap Begin?](../experiments/logic/sorites.md) — Try to draw a boundary and explain its purpose.
9. [The Monty Hall Problem](../experiments/mathematics/monty-hall.md) — Write out the host’s rule before calculating.
10. [The Prisoner’s Dilemma](../experiments/economics/prisoners-dilemma.md) — Explain why an individually tempting choice can hurt both players.

Read each article’s scenario first, write an initial answer, and then read the interpretations and sources. Spend as long as useful; there is no required schedule.

## Reflection questions

- Which answer changed when a hidden premise became explicit?
- Which case makes a useful point even if its imagined technology is impossible?

## Final synthesis activity

Choose two cases from different categories. Write a one-page comparison with five labelled parts: scenario, assumptions, initial answer, strongest objection, revised answer. There is no answer key for your values; the test is whether your reasons respond to the objection.
