# Reality, Knowledge, and Skepticism

Begin with radical doubt, then narrow the question to what makes an ordinary belief count as knowledge. Distinguish a skeptical possibility from evidence that the possibility is actual.

## Learning objectives

- Separate truth, justification, knowledge, and certainty.
- Explain epistemic luck.
- Assess whether changing a description changes a skeptical argument.

## Recommended sequence

1. [The Dream Argument](../experiments/epistemology/dream-argument.md) — Ask how waking belief could be distinguished from a dream.
2. [Descartes’s Evil Demon](../experiments/epistemology/evil-demon.md) — Consider doubt even when reasoning seems clear.
3. [Brain in a Vat](../experiments/epistemology/brain-in-a-vat.md) — Compare a technological scenario with the demon.
4. [Gettier Cases](../experiments/epistemology/gettier-cases.md) — Test justified true belief without radical skepticism.
5. [Fake-Barn Country](../experiments/epistemology/fake-barn.md) — Ask whether an unreliable environment defeats knowledge.
6. [Molyneux’s Problem](../experiments/epistemology/molyneux-problem.md) — Consider the relation between senses and learning.

Read each article’s scenario first, write an initial answer, and then read the interpretations and sources. Spend as long as useful; there is no required schedule.

## Reflection questions

- Must knowledge rule out every conceivable alternative?
- How does luck differ in the Gettier and fake-barn cases?

## Final synthesis activity

Construct an argument map for one skeptical claim: premises, conclusion, and two possible objections. Then give an ordinary example where you would still claim knowledge. Explain whether that is a contradiction or a change in standards.
